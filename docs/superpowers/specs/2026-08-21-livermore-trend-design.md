# 利弗莫尔趋势管仓回测设计

日期：2026-08-21  
状态：已实现

## 背景

现有 `alpha_a_share` 策略多为「ML/因子选前 1/3 → 等权持仓 + 止损/移动止盈」。  
用户希望新增利弗莫尔式趋势管仓：在 ML 候选内做突破买入、顺势加仓、回撤减仓/清仓，并与现有策略在同一回测区间对比。

## 目标

1. 新增独立一年回测脚本 `examples/alpha_a_share/backtest_1y_livermore.py`
2. 策略模式：**ML 筛股 + 利弗莫尔管仓**（不改动每日 `predict_daily.py`）
3. **输出必须与现有策略同区间对比**（强制，不是可选项）

## 非目标（第一版不做）

- 不改 `predict_daily.py` 的买卖建议展示
- 不引入组合级回撤熔断（参数可预留，默认关闭）
- 不做实盘下单

## 策略规则

### ML 候选

- 使用与现有一年回测相同的训练/回测切分与 LightGBM（主持有期 3 日信号）
- 每日取信号前约 `1/3` 股票为候选池

### 买入

- 条件：在候选池内、当前无仓、收盘价创近 **N=20** 日新高
- 动作：建首仓 = 该股预算的 **40%**

### 加仓（金字塔，不摊平）

- 相对「上一次买入价」再上涨 **X%** 才允许加一档
- 档位比例：**30% / 20% / 10%**（最多再加 3 次）
- 价格下跌或未达间距：**不加仓**

### 减仓 / 清仓

- **止损清仓**：相对加权成本亏损 ≥ **7%** → 全清
- **移动止盈**：
  - 持仓最高价相对成本先涨到 **A=15%** 后启动
  - 从最高点回撤 ≥ **B=8%** → **先减半**
  - 之后若继续满足清仓条件（再回撤或破成本止损）→ **清仓**
- 掉出 ML 候选：**不强制卖**，仍按止损/移动规则管理

### 资金

- 账户资金在「当日有持仓或新建仓的股票」间大致均分，得到单股预算
- 单股预算按 40/30/20/10 使用；未用满部分留现金

## 同区间对比（强制输出）

回测区间与现有脚本对齐，例如：

- 训练：`2023-01-01 ~ 2025-06-28`
- 回测：`2025-06-29 ~ 2026-06-29`

同一信号、同一股票池、同一资金与费率下，至少对比：

| 策略 | 说明 |
|------|------|
| 基准 A | ML 等权 Top1/3（无个股止损止盈，或与 `backtest_1y.py` 同逻辑） |
| 基准 B | ML 等权 + 现有移动止盈（A=15%/B=8%，止损 7%，对齐 `backtest_1y_circuit` 个股规则、无组合熔断） |
| 本策略 | ML + 利弗莫尔金字塔管仓 |

终端打印对比表，字段至少包含：

- 年化收益、总收益、夏普、最大回撤%、收益回撤比、结束资金、成交笔数
- 利弗莫尔专属：建仓次数、加仓次数、减半次数、止损清仓次数

结果写入：`alpha_data/livermore_result.json`（含各策略统计与参数）。

## 参数

| 参数 | 第一版 |
|------|--------|
| 突破窗口 N | 20 |
| 加仓间距 X | 网格：5%, 8%, 10%（对利弗莫尔策略扫描；基准固定） |
| 金字塔 | 40/30/20/10 |
| 止损 | 7% |
| 移动 A/B | 15% / 8% |
| 组合熔断 | 关闭 |

网格以夏普为主排序，并打印相对基准 B 的年化/夏普/回撤差值。

## 实现要点

- 复用 `stock_universe.py`、`datafeed.py`、现有合约配置方式
- 策略类继承 `AlphaStrategy`，用 `set_target` 表达目标股数
- 维护每只股票：成本、持仓最高价、上次买入价、已用金字塔档位、是否已减半

## 验收

1. 脚本可独立跑通一年回测
2. 终端有「基准 A / 基准 B / 利弗莫尔」同区间对比表
3. JSON 结果落盘
4. 不改动 `predict_daily.py` 行为
