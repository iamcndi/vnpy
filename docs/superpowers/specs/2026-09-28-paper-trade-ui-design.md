# 模拟操盘 Web UI（第一期）设计

日期：2026-09-28  
状态：待用户确认后实现

## 1. 目标

在本地浏览器提供「模拟操盘训练」界面：用**新的模拟账户**、按**可选交易日**的日线收盘价手动买入/卖出，并支持持仓查看与历史复盘。

第一期**不包含**：模型训练（`run_ml`）、每日预测集成、利弗莫尔自动建议、实时行情。

## 2. 与现有项目的关系

| 复用 | 路径/模块 |
|------|-----------|
| 日线行情 | `alpha_data/daily/*.parquet` |
| 股票池解析 | `stock_universe.py` |
| 账本读写 | `livermore_positions_store.py` |
| 涨跌停幅度 | 复用/抽取 `predict_daily.a_share_daily_limit_up_pct` 同类规则 |

模拟账户与实盘账户（默认、中信、兴业等）隔离；行情只读复用历史日线。

## 3. 技术方案

- **形态**：本地 Gradio 单应用  
- **入口**：`examples/alpha_a_share/app_paper_trade.py`  
- **启动**：`.venv/bin/python examples/alpha_a_share/app_paper_trade.py` → `http://127.0.0.1:7860`  
- **依赖**：`gradio` 加入 `examples/alpha_a_share/requirements.txt`

## 4. 界面结构（三页签）

### 4.1 下单

- 选择**模拟账户**（仅列出名称前缀 `模拟_` 的账户）
- 方向：买入 / 卖出
- 字段：代码、数量（整手 100）、**交易日**、价格
- 价格默认 = 该股在所选交易日的日线收盘，可手动改
- 可选：下单前增量更新该股日线
- 提交后显示成功/失败原因；成功则刷新持仓摘要

### 4.2 持仓

- 选模拟账户 + **估值日**（默认与下单页交易日一致）
- 展示：现金、各标的股数/成本/估值日收盘、市值、持仓盈亏、当日盈亏（相对上一交易日收盘）
- 合计权益

### 4.3 历史

- 选模拟账户，展示 `livermore_positions_history.jsonl` 最近 N 条（默认 50）
- 可按交易日筛选
- 字段：记录时间、交易日、动作、代码、数量、价格、成交后现金、备注

## 5. 账户规则

- 创建模拟账户时强制名称以 `模拟_` 开头（用户只填后缀亦可自动补全）
- 创建参数：名称、初始资金、`updated` 初始交易日（可选，默认今天）
- 存储：`alpha_data/accounts/<账户名>/livermore_positions.json` + `..._history.jsonl`
- 界面下拉**只显示**模拟账户，避免误改实盘账本

## 6. 下单与成交规则

### 6.1 基础校验

- 代码须能解析为 `vt_symbol`（优先股票池；池外若本地已有日线也可允许，名称用代码占位）
- 数量 &gt; 0 且为 100 整数倍
- 所选交易日须存在该股日线；无数据则拒绝并提示下载/换日
- 买入：`现金 ≥ 成交金额 + 买入费用`
- 卖出：持仓股数 ≥ 卖出数量
- 费率（与现有回测一致）：买 `0.00025`，卖 `0.00125`（含印花税量级）

### 6.2 涨跌停校验（本期加入）

以**该股上一交易日收盘**为昨收 `pre_close`，按板块确定日涨跌幅 `ratio`：

| 类型 | 幅度 |
|------|------|
| ST/*ST | ±5% |
| 创业板 300/301、科创板 688 | ±20% |
| 北交所 | ±30% |
| 其余 A 股主板 | ±10% |
| 港股等 | 不做涨跌停校验 |

计算：

- 涨停价 = `round(pre_close * (1 + ratio), 2)`
- 跌停价 = `round(pre_close * (1 - ratio), 2)`

规则：

1. **成交价必须落在 \[跌停价, 涨停价\]**（含边界）；超出则拒绝。  
2. **买入**：若所选交易日收盘价已触及涨停价（一字/收盘涨停），默认**拒绝买入**（与现网「涨停暂不可买」一致）；界面可显示「涨停不可买」。  
3. **卖出**：若所选交易日收盘价已触及跌停价，默认**拒绝卖出**；界面可显示「跌停不可卖」。  
4. 无昨收（上市首日等）时跳过涨跌停校验，但提示「无昨收，未做涨跌停检查」。

实现上抽取公共函数（如 `a_share_limit_prices` / `is_a_share_limit_down`），供 UI 与 `predict_daily` 共用，避免两套规则。

### 6.3 账本更新

- 买入：扣现金（含费）、增加/合并持仓；`merge_broker_position` 更新成本与 `high`；`last_buy` 取本次买入价  
- 卖出：减持仓、加回现金（成交额 − 卖出费用）；股数为 0 则移除该标的  
- `updated` 设为本次**交易日**  
- 历史流水 `note` 示例：`模拟买入 000333 200@82.47 交易日=2026-09-23`  
- `source`：`paper_trade`

## 7. 复盘

- 历史列表即主复盘入口  
- 持仓页按估值日用当日收盘估值  
- 第一期不做完整「时光机回放重建任意日账本」；若需要某日终态，以该日及之前最后一条流水快照为准（若 `history_on_or_before` 已具备则复用）

## 8. 非目标（后续期）

- 接入 `run_ml` / `predict_daily` / 评估优化  
- 分钟线、盘口、滑点、部分成交  
- 实盘账户在本 UI 中编辑

## 9. 验收

1. 可创建 `模拟_练习1`，初始资金正确  
2. 任选历史交易日，按默认收盘价买入股票池内标的，持仓与现金正确  
3. 涨停日买入被拒绝；跌停日卖出被拒绝；手工改价超出涨跌停板被拒绝  
4. 卖出后现金与持仓正确，历史可查  
5. 实盘账户名不出现在模拟下拉列表中
